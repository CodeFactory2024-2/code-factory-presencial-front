# SITAS - Flight Management Module
![flight_management_mockup](https://github.com/user-attachments/assets/75c1cf7e-3016-48c5-9a33-e57fe7f2e324)

Visit the website 🌐 [https://codefactory-gestion-de-vuelos-b.vercel.app/](https://codefactory-gestion-de-vuelos-b.vercel.app/)

This project is the implementation of a flight and airplane type management system, created for the CodeFactory 2024-2 project, at the University of Antioquia. The application allows the administration of flights and airplane types, allowing airline administrators to maintain control of the flights and airplane models that are available in the airline.

## Running

1. Clone the repository

```bash
git clone https://github.com/CodeFactory2024-2/code-factory-presencial-front.git
```

2. Change the working directory and branch

```bash
cd code-factory-presencial-front
git switch gestion-de-vuelos-B
```

3. Install dependencies

```bash
npm install
```

4. Run the development server or build the project and run the server

```bash
npm run dev

# or
npm run build
npm run start
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
